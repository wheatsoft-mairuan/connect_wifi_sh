# connect_wifi_sh
一个用于管理WiFi的脚本
仅适用于以安装并能正常运行Network Manager的linux主机
A script for managing WiFi
Only applicable to Linux hosts with Network Manager installed and functioning properly

用法：
  1. 安装NetworkManager（必须）
  2. 下载仓库内的"wifi.sh
  3. 为脚本赋予运行权限
  4. 运行

Usage:
  1. Install NetworkManager (required)
  2. Download the "wifi.sh" file from the repository
  3. Grant execute permissions to the script
  4. Run
